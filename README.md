# POKÉ LUCK — 1~3인 경쟁 생존 디펜스

기존 땅따먹기 게임을 각자의 구역에서 웨이브를 방어하는 포켓몬 1세대 팬 게임으로 변경했습니다. 현재 20종이 구현되어 있습니다.

## 시작하기

```sh
pip install -r requirements.txt
python server.py
```

`http://localhost:8080`을 열어 방을 만들고 **지금 시작**을 누릅니다. 다른 사람을 기다리지 않고 혼자 시작할 수 있습니다. 친구와 경쟁하려면 시작 전에 초대 링크를 공유하세요. 최대 3명까지 참가할 수 있고, 시작 후 새 참가자는 입장할 수 없습니다.

- 1인: 생명이 모두 소진될 때까지 도전하는 솔로 생존 모드
- 2~3인: 각자 생명 20으로 시작하며 마지막 생존자가 승리
- 같은 서버 틱에 마지막 참가자들이 함께 탈락하면 무승부
- 연결이 끊겨도 경기는 계속 진행되고 기존 포켓몬이 자동 방어
- 30초 안에 같은 브라우저 탭을 새로고침하면 토큰으로 복귀, 30초가 지나면 해당 참가자 탈락
- 방장이 나가면 접속 중인 참가자에게 방장 권한 이전
- 재대결은 현재 접속한 참가자만으로 즉시 시작

## 플레이

- 랜덤 소환 40코인, 최대 12마리 배치, 기본 2마리 무료 제공
- 일반 70%, 희귀 23%, 에픽 6%, 전설 1% (각 등급 내 동일 확률)
- 같은 포켓몬·같은 강화 단계 3마리 합성 → 다음 진화. 최종 진화는 공격력 2배
- 포켓몬 클릭으로 선택, 빈 칸 클릭으로 이동
- 팀 공격 강화: 70코인부터 단계별 40코인 증가, 최대 10단계
- 습격 80코인: 모든 생존 상대에게 강화 적 1마리, 재사용 15초
- 24초마다 다음 웨이브, 5웨이브마다 보스
- 적이 경로를 완주하면 일반 1 / 습격 2 / 보스 5 생명 감소
- 불·전기·에스퍼 다중 공격, 풀·물·얼음 둔화, 모든 공격 치명타 확률 15%
- 경쟁 중 다른 참가자의 필드를 관전할 수 있음

전투·확률·코인·합성·배치·습격·승패는 서버가 판정합니다. 클라이언트는 행동 요청만 전송합니다. 공식 게임의 규칙이나 밸런스를 그대로 재현하지 않은 초기 버전이며 실제 플레이에 따른 밸런스 조정이 필요합니다.

## Render

기존 `render.yaml`의 Python Web Service, 시작 명령(`python server.py`), `/api/health`를 그대로 사용합니다. 서버는 `0.0.0.0` 및 Render의 `PORT` 환경 변수에 바인딩합니다. 이 변경만으로 Render에 배포되지는 않습니다. 기본 브랜치에 병합하고 연결된 Render 서비스의 배포를 확인하세요.

방 상태는 단일 프로세스 메모리에 있으므로 서버 재시작·재배포 시 경기가 초기화됩니다. 여러 인스턴스로 확장하려면 공용 상태 저장소가 필요합니다.

캐릭터 이미지는 PokeAPI sprites 공개 GitHub 저장소에서 불러옵니다. 이미지 접속이 실패해도 도감 번호·이름으로 플레이할 수 있습니다. 포켓몬 관련 권리는 각 권리자에게 있습니다. 비공식 팬 게임입니다.

## 검증

```sh
python -m unittest discover -v
node --check assets/client.js
```

규칙 테스트 및 실제 aiohttp HTTP/WebSocket 통합 테스트가 포함되어 있습니다. GitHub Actions도 같은 검사를 수행합니다.
