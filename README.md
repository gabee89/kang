# POKÉ LUCK — 1~3인 경쟁 생존 디펜스

혼자 즉시 시작하거나 2~3명이 각자 방어하며 마지막 생존자를 겨룹니다. 시작 전에 초대 링크를 공유하세요.

## 실행 / Render

`pip install -r requirements.txt` 후 `python server.py`를 실행하고 http://localhost:8080 에 접속합니다. Render는 기존 render.yaml을 사용합니다. 0.0.0.0 / PORT에 바인딩하며 /api/health를 제공합니다.

방은 단일 프로세스 메모리에 저장되어 재배포·재시작 시 초기화됩니다. 연결이 끊겨도 자동 방어를 유지하며 실제 시간 30초 안에 재접속할 수 있습니다. 방장 이탈 시 접속 중인 참가자에게 권한을 이전합니다.

## 36칸 배치 / 판매 / 진화 / +10 강화

- 배치 36칸, 무료 2마리. 소환 40코인, 등급별 확률 70/23/6/1%.
- 드래그 또는 배치 버튼으로 이동·교환. 작은 화면에서는 보유 포켓몬 목록과 행/열 선택으로도 배치할 수 있습니다.
- 판매액: 일반 15 / 희귀 30 / 에픽 60 / 전설 120코인 × (1+최종 강화 단계). 판매 후 다시 소환할 수 있습니다.
- 진화 전: 동일 포켓몬·동일 강화 단계 3마리 → 다음 진화 1마리.
- 최종 진화: 동일 포켓몬·동일 강화 단계 2마리 → +1 강화, 최대 +10.
- 최종 강화 단계마다 기본·필살 피해 +40%. 선택한 자리와 ID를 유지하고 게이지를 초기화합니다.
- 선택 창에 기본/필살 피해, 공격 간격, 사거리, 상태이상, 판매액, 다음 진화/강화 재료 수를 표시합니다.

## 속성별 상태이상

| 속성 | 개성 |
|---|---|
| 불 | 화상: 매초 공격 피해의 12%, 기본 3초 / 필살 5초. 강한 피해·지속시간 갱신 |
| 풀 | 중독: 매초 공격 피해의 6% × 중첩, 최대 3중첩, 5초. 필살은 2중첩 추가 |
| 전기 | 마비: 기본 30% 확률 0.55초 정지 / 필살 1.3초, 재마비 면역 3초 |
| 얼음 | 냉기: 이동 -65%, 기본 1.8초 / 필살 3초 |
| 물 | 이동 -35% 및 젖음: 기본 3초 / 필살 5초 동안 전기 피해 +25% |
| 고스트 | 저주: 받는 피해 +15%, 기본 2초 / 필살 5초 |
| 에스퍼 | 약점 노출: 기본 3초 / 필살 5초 안의 다음 직접 공격 한 번에 피해 +50% |

보스는 둔화 최대 -35%, 마비 기본 0.15초 / 필살 0.4초, 재마비 면역 4초입니다.

## 기술과 연출

근거리 사거리 2.15 / 기본 피해 계수 1.9, 원거리 사거리 4.4 / 계수 1입니다. 기술마다 피해·공격 간격을 다르게 정했습니다. 예: 전기쇼크 0.6초·계수 0.7, 베어가르기 1.15초·1.25, 섀도펀치 1.25초·1.5. 치명타 15% 확률 2배이며 등급·팀 강화·최종 강화·지형도 피해에 반영합니다.

초당 7 및 기본 공격마다 18 게이지 충전. 100에서 대상이 있으면 필살기 자동 발동, 최대 8마리, 사거리 +1.4. 대상이 없으면 대기합니다. 필살기별 피해 배율은 10만볼트 3.2, 화염방사 3.4, 눈보라 3.8, 섀도볼 4, 하이드로펌프 4.2, 사이코키네시스 4.5, 번개 4.6, 솔라빔 4.8, 불대문자 5, 파괴광선 6 등입니다.

불꽃·풀잎·물방울·번개·얼음 결정·고스트 구체, 기술명 배너, 진화/강화 섬광과 스프라이트 교체 연출을 제공합니다. 포켓몬·야생 적 31종, 총 719프레임의 로컬 애니메이션을 사용합니다. 외부 이미지 로딩에 의존하지 않습니다.

기술 조합은 [PokeAPI 학습 기술 데이터](https://github.com/PokeAPI/api-data/tree/master/data/api/v2/pokemon)에서 확인했습니다. 1세대 포켓몬에 후속 세대 습득 기술도 포함하며, 수치와 상태이상은 팬 게임용 규칙입니다.

## 난이도 / 웨이브 / 배속

- 방장이 대기실에서 보통 / 도전(기본) / 극한을 선택합니다.
- 20초마다 웨이브, 체력은 라운드 제곱·누적 배율로 증가합니다.
- 빠른 적, 피해 30% 감소 방어형, 보호막 적이 섞입니다. 4라운드부터 일부 적이 오른쪽 샛길로 기습합니다.
- 5·15·25라운드 중간보스 롱스톤, 10·20·30라운드 보스 망나뇽. 보스는 중간보스보다 체력 계수가 두 배입니다.
- 처치 보상: 일반 5 / 중간보스 25 / 보스 60코인. 3웨이브마다 황금 나옹 추가 25코인.
- 방장이 1/2/3배속을 변경합니다. 모든 참가자에게 같은 배율을 적용하고 전투·상태이상·웨이브를 고정 소단계로 계산합니다. 재접속 30초는 실제 시간입니다.
- 습격 80코인으로 모든 생존 상대에게 강화 적 1마리, 재사용 15초. 상대 필드 관전 지원.

서버와 화면은 같은 assets/map.json을 읽습니다. 숲·연못·다리·돌길·동굴·회복 기지, 진흙길 -35% / 바람길 +35%, 같은 타입 배치 공격 +25%가 있습니다.

## 검증

`python -m unittest discover -v` 및 assets/client.js, battlefield.js, combat-fx.js, actors.js, element-fx.js의 `node --check`를 실행합니다. GitHub Actions가 규칙·경제·권한·동기화·36칸·판매·상태이상·강화·보스·배속·PNG 자산을 검사합니다.

비공식 팬 게임이며 포켓몬 관련 권리는 각 권리자에게 있습니다. 스프라이트 출처: assets/sprites/SOURCE.md.
