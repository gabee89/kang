# POKÉ LUCK — 1~3인 경쟁 생존 디펜스

혼자 즉시 시작하거나 2~3명이 각자 방어하며 마지막 생존자를 겨룹니다. 시작 전에 초대 링크를 공유하세요.

## 실행 / Render

`pip install -r requirements.txt` 후 `python server.py`를 실행하고 http://localhost:8080 에 접속합니다. Render는 기존 render.yaml을 사용합니다. 0.0.0.0 / PORT에 바인딩하며 /api/health를 제공합니다.

방은 단일 프로세스 메모리에 저장되어 재배포·재시작 시 초기화됩니다. 연결이 끊겨도 자동 방어를 유지하며 실제 시간 30초 안에 재접속할 수 있습니다. 방장 이탈 시 접속 중인 참가자에게 권한을 이전합니다.

## 36칸 배치 / 판매 / 진화 / +10 강화

- 배치 36칸, 무료 2마리. 소환 40코인, 기본형 96% / 중간 진화 3% / 최종 진화 0.7% / 전설 0.3%.
- 모바일에서는 하단 고정 조작바로 맵을 보며 소환·공격 강화·합성·판매합니다. 정보·배치 버튼은 접이식 상세 창을 엽니다.
- 드래그 또는 배치 버튼으로 이동·교환. 작은 화면에서는 보유 포켓몬 목록과 행/열 선택으로도 배치할 수 있습니다.
- 판매액: 일반 15 / 희귀 30 / 에픽 60 / 전설 120코인 × (1+최종 강화 단계). 판매 후 다시 소환할 수 있습니다.
- 진화 전: 동일 포켓몬·동일 강화 단계 3마리 → 다음 진화 1마리.
- 최종 진화: 동일 포켓몬·동일 강화 단계 2마리 → +1 강화, 최대 +10.
- 최종 강화 단계마다 기본·필살 피해 +40%. 선택한 자리와 ID를 유지하고 게이지를 초기화합니다.
- 선택 창에 기본/필살 피해, 공격 간격, 사거리, 상태이상, 판매액, 다음 진화/강화 재료 수를 표시합니다.

## 속성별 상태이상

| 속성 | 개성 |
|---|---|
| 불 | 화상: 매초 공격 피해의 12%, 기본 3초 / 필살 5초. 강한 피해·지속시간 갱신 |
| 풀 | 중독: 매초 공격 피해의 6% × 중첩, 최대 3중첩, 5초. 필살은 2중첩 추가 |
| 전기 | 마비: 기본 30% 확률 0.55초 정지 / 필살 1.3초, 재마비 면역 3초 |
| 얼음 | 냉기: 이동 -65%, 기본 1.8초 / 필살 3초 |
| 물 | 이동 -35% 및 젖음: 기본 3초 / 필살 5초 동안 전기 피해 +25% |
| 고스트 | 저주: 받는 피해 +15%, 기본 2초 / 필살 5초 |
| 에스퍼 | 약점 노출: 기본 3초 / 필살 5초 안의 다음 직접 공격 한 번에 피해 +50% |

보스는 둔화 최대 -35%, 마비 기본 0.15초 / 필살 0.4초, 재마비 면역 4초입니다.

## 기술과 연출

근거리 사거리 2.15 / 기본 피해 계수 1.9, 원거리 사거리 4.4 / 계수 1입니다. 기술마다 피해·공격 간격을 다르게 정했습니다. 예: 전기쇼크 0.6초·계수 0.7, 베어가르기 1.15초·1.25, 섀도펀치 1.25초·1.5. 치명타 15% 확률 2배이며 등급·팀 강화·최종 강화·지형도 피해에 반영합니다.

초당 7 및 기본 공격마다 18 게이지 충전. 100에서 대상이 있으면 필살기 자동 발동, 최대 8마리, 사거리 +1.4. 대상이 없으면 대기합니다. 필살기별 피해 배율은 10만볼트 3.2, 화염방사 3.4, 눈보라 3.8, 섀도볼 4, 하이드로펌프 4.2, 사이코키네시스 4.5, 번개 4.6, 솔라빔 4.8, 불대문자 5, 파괴광선 6 등입니다.

불꽃·풀잎·물방울·번개·얼음 결정·고스트 구체, 기술명 배너, 진화/강화 섬광과 스프라이트 교체 연출을 제공합니다. 포켓몬·야생 적 32종, 총 743프레임의 로컬 애니메이션을 사용합니다. 외부 이미지 로딩에 의존하지 않습니다.

기술 조합은 [PokeAPI 학습 기술 데이터](https://github.com/PokeAPI/api-data/tree/master/data/api/v2/pokemon)에서 확인했습니다. 1세대 포켓몬에 후속 세대 습득 기술도 포함하며, 수치와 상태이상은 팬 게임용 규칙입니다.

## 난이도 / 웨이브 / 배속

- 방장이 대기실에서 보통 / 도전(기본) / 극한을 선택합니다.
- 20초마다 웨이브, 체력은 라운드 제곱·누적 배율로 증가합니다.
- 빠른 적, 피해 30% 감소 방어형, 보호막 적이 섞입니다. 4라운드부터 일부 적이 오른쪽 샛길로 기습합니다.
- 5·15·25라운드 중간보스 롱스톤, 10·20·30라운드 보스 망나뇽. 보스는 중간보스보다 체력 계수가 두 배입니다.
- 처치 보상: 일반 5 / 중간보스 25 / 보스 60코인. 3웨이브마다 황금 나옹 추가 25코인.
- 방장이 1/2/3배속을 변경합니다. 모든 참가자에게 같은 배율을 적용하고 전투·상태이상·웨이브를 고정 소단계로 계산합니다. 재접속 30초는 실제 시간입니다.
- 습격 80코인으로 모든 생존 상대에게 강화 적 1마리, 재사용 15초. 상대 필드 관전 지원.

서버와 화면은 같은 assets/map.json을 읽습니다. 숲·연못·다리·돌길·동굴·회복 기지, 진흙길 -35% / 바람길 +35%, 같은 타입 배치 공격 +25%가 있습니다.

## 검증

`python -m unittest discover -v` 및 assets/client.js, battlefield.js, combat-fx.js, actors.js, element-fx.js의 `node --check`를 실행합니다. GitHub Actions가 규칙·경제·권한·동기화·36칸·판매·상태이상·강화·보스·배속·PNG 자산을 검사합니다.

비공식 팬 게임이며 포켓몬 관련 권리는 각 권리자에게 있습니다. 스프라이트 출처: assets/sprites/SOURCE.md.

## 개체값과 육성의 의미

소환마다 공격·특공·스피드 개체값을 각각 0~31로 부여합니다. 공격은 근거리 기본 공격과 몸통박치기 필살, 특공은 원거리 기본 공격과 나머지 필살 피해를 0.9~1.1배로 조정합니다. 스피드는 공격 간격을 최대 12% 줄입니다. 이 디펜스에서 사용하는 3종 개체값이며 원작의 모든 능력치를 재현한 것은 아닙니다. 선택 창에 개체값과 반영된 실제 피해·공격 간격을 표시합니다. 합성과 경험치 진화는 선택한 유닛의 개체값을 유지합니다.

3단계 계열은 중간 형태 1.3배 / 최종 1.9배, 2단계 계열은 최종 1.8배, 무진화 계열은 처음부터 1.2배의 계열 성장 계수를 적용합니다. 직접 육성해 진화시킨 횟수당 추가 15% 성장 보너스가 있습니다. 기본형 중심 소환으로 바꾸고 무진화 일반 전력으로 라프라스를 추가했습니다.

처치할 때 현재 배치한 모든 포켓몬은 경험치 1을 얻습니다. 3단계 첫 진화는 400, 두 번째는 1,000, 2단계 진화는 650 경험치가 필요합니다. 기준을 채우면 자동 진화합니다. 진화 후 초과 경험치는 남고 합성 재료의 경험치도 합산해 보존합니다. 최종/무진화 포켓몬은 경험치로 다른 종으로 바뀌지 않으며 2마리 합성 +10 강화 경로를 이용합니다. 경험치는 해당 경기 안에서만 유지되고 재대결 시 초기화됩니다.

## 전장 가독성

불대문자는 불꽃으로 된 大 글자가 시전자에게서 주 대상에게 실제로 날아갑니다. 솔라빔·화염방사·하이드로펌프·10만볼트·번개·섀도볼·눈보라·사이코키네시스·파괴광선은 각각 다른 전용 연출을 사용합니다. 전체 화면 색 덮기를 없애고, 큰 범위 이펙트 복제를 줄였습니다. 동시에 표시하는 기본 공격 20개 / 필살기 3개 / 진화 연출 2개로 제한하며 피해 계산은 그대로 유지합니다.

## 근거리 / 원거리 약점 몬스터

3라운드부터 일부 적에게 근거리 또는 원거리 약점이 부여됩니다. 해당 방식 피해는 1.6배, 반대 방식은 0.55배이며 중립 적은 1배입니다. 몬스터 머리 위에 약점을 표시합니다. 5·15라운드 중간보스는 근거리 약점 / 원거리 저항, 10·20라운드 보스는 원거리 약점 / 근거리 저항이며 보스 안내에도 표시됩니다. 동일 웨이브의 모든 참가자에게 같은 약점 규칙을 적용합니다.

기본 공격은 포켓몬의 기본 공격 방식으로, 궁극기는 기술별 방식으로 계산합니다. 몸통박치기 궁극기는 근거리, 나머지 현재 궁극기는 원거리입니다. 화상·독은 발생시킨 공격의 방식을 유지해 저항을 우회하지 않습니다. 방어형의 방어력과 보호막도 함께 적용됩니다.

## 모바일 가로 플레이와 부드러운 이동

휴대폰을 가로로 돌리면 맵을 중심으로 왼쪽 참가자 상태, 오른쪽 소환·합성·판매 조작바를 표시합니다. 667/844/915px 가로 화면에서 스크롤 없이 맵과 조작부가 들어오도록 배치했습니다. 세로 화면에는 회전 안내가 표시되고 세로 계속하기도 가능합니다. 전체화면 버튼은 브라우저가 지원하는 경우에만 전체화면과 가로 방향 잠금을 요청하며, 지원하지 않으면 직접 기기를 돌려 플레이할 수 있습니다. 데스크톱의 기존 배치는 유지합니다.

렌더러는 서버 위치를 90ms 버퍼로 보간하고 통신 지연 시 추정 이동은 30ms로 제한합니다. 유닛 자리 이동은 180ms 동안 부드럽게 연결합니다. 과한 부유·좌우 회전·공격 튀김을 줄였습니다. 전투·사거리·피해 판정은 서버 위치를 그대로 사용합니다. Motion 검사는 node test_motion.cjs로 실행합니다.


### 곡선 계곡과 소환 행운
- 서버와 화면이 동일한 121개 곡선 표본과 누적 거리를 사용합니다. 근거리 사거리 2.1, 원거리 3.9, 필살 3.25/5.05. 36개 배치 칸 모두 근거리로 길을 공격할 수 있습니다.
- 개인 코인으로 소환 확률을 5단계 강화합니다. 비용 100/190/280/370/460. 기본 96/3/0.7/0.3% → 최대 85.5/10/3.45/1.05% (기본/중간/최종/전설). 합성·경험치 진화는 유지됩니다.
- 생성한 숲 배경, 석조 포털, 방어 기지, 곡선 포장도로, 입체 UI. 캐릭터 원화는 기존 에셋을 유지하고 부드러운 렌더링과 그림자를 적용합니다.
