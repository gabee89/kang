# POKÉ LUCK — 1~3인 전략 디펜스

이 브랜치는 운영 게임을 확장하는 검토용 변경입니다. 기존 이미지·애니메이션과 50라운드 경쟁/협동전을 유지합니다.

## 실행과 검증

`pip install -r requirements.txt`, `python server.py`, http://localhost:8080
서버는 PORT/0.0.0.0 및 GET /api/health를 사용합니다. Render 설정은 변경하지 않았습니다.

`python -m unittest discover -v`로 규칙·경제·실제 WebSocket·카드/미션/지원·보스·결과를 검사합니다.
모든 assets/*.js에 `node --check`를 적용하고 `node test_motion.cjs`를 실행합니다.

## 현재 전장과 성장

- 배치 지점은 **24개**, 이론상 최대 72마리입니다. 진화 가능한 종류는 지점당 3마리, 최종형/무진화는 2마리입니다.
- 지점은 이동/드래그 중에만 보입니다. 같은 종류 소환은 기존 중첩부터 채우며 같은 지점의 묶음은 함께 이동/합치기/자리 교환됩니다. 공간 부족 시 일부를 떼지 않습니다.
- 진화 전 동일 종류·power·강화의 3마리 합성. 최종형/무진화는 같은 종류 2마리로 높은 강화 단계+1, 최대 +10입니다. 낮은 단계 재료를 우선하고 +10을 재료로 소모하지 않습니다.
- 개체값 공격/특공/스피드는 각 재료의 최고값, 경험치는 합산합니다. 경험치 자동 진화는 3단계 400/1000, 2단계 650입니다.
- 근거리 1.0, 원거리 약 두 칸인 2.1이며 필살기에도 같은 범위를 씁니다. 별도 공동 보스전은 전원 참전합니다.
- 풀숲: 공격 속도 +15%(풀 +20%), 화염: 피해 +15%(불 +25%), 호수: 게이지 +25%(물/얼음 +40%), 수정: 필살 +20%(전기 +30%), 폐허: 치명타 +5%p(고스트 +10%p). 다섯 지역은 양쪽에 분산돼 있습니다.
- 배경 풀길에 반투명 선과 화살표를 표시하며 라운드별 정/역방향을 서버가 무작위 선택합니다. 4의 배수 일반 라운드는 샛길에서 진입합니다.
- 일반 적은 라운드별 한 종류이며 모든 참가자가 같은 종류·복합 속성·날씨를 공유합니다. 황금 적도 같은 종류입니다. 5의 배수 중간보스와 10의 배수 공동 보스는 별도입니다.
- 맑음/비/폭염/눈/바람은 연속 반복되지 않습니다. 날씨는 공격 속성에만 적용하고 지역 버프를 켜거나 끄지 않습니다. 상단 배경 효과 자동/켜기/끄기로 움직임을 제어합니다.
- 방 상태는 메모리에 있어 재시작 시 초기화됩니다. 재접속 유예는 실제 시간 30초이며 그동안 자동 방어를 유지합니다. 방장 이탈 시 접속 참가자에게 이전합니다.

## 운명의 선택

5/15/25/35/45R 성공 후 생존 플레이어마다 독립된 카드 3장을 제시합니다. 정비는 실제 시간 18초이며 미선택자는 서버가 자동 선택합니다. 선택은 한 번만 적용됩니다.

| 카드 | 효과 | 최대 중첩 |
|---|---|---:|
| 불꽃의 가호 | 불 피해 +15% | 2 |
| 번개의 축복 | 전기 게이지 +15% | 2 |
| 얼음의 지배자 | 얼음 피해 +12% | 2 |
| 자연의 힘 | 풀 공격 속도 +12% | 2 |
| 행운의 손길 | 처치 코인 +10%, 소수 보너스 이월 | 2 |
| 황금의 계약 | 즉시 150코인 | 2 |
| 치명적 집중 | 치명타 +5%p | 2 |
| 필살기 전문가 | 필살 피해 +12% | 2 |
| 진화의 축복 | 합성·진화당 30코인, 라운드당 2회 | 1 |
| 굳건한 방어 | 생명 2 회복, 시작 상한 이내 | 2 |

협동 다인전의 방어 카드는 팀 생명을 회복합니다. 경쟁/솔로에서는 개인 생명을 회복합니다.

## 특별 미션과 시너지

1/11/21/31/41R에 플레이어별 미션을 한 개 부여합니다. 해당 10라운드 구간까지 유효하며 보상은 자동·1회 지급합니다.

- 사냥꾼: 구간 처치 30, 100코인.
- 완벽한 방어: 생명 손실 없는 연속 2라운드 성공, 120코인. 중간 회복으로 손실을 숨길 수 없습니다.
- 속성 수집가: 4속성 동시 보유, 100코인.
- 진화 전문가: 합성·경험치 진화 3회, 120코인.
- 보스 사냥꾼: 공동 보스 최대 HP의 10% 이상 피해 기여, 150코인.

각 속성 2마리 이상일 때 활성화하며 판매·합성·진화 후 현재 수량으로 다시 계산합니다.

| 시너지 | 조건 | 해당 속성 효과 |
|---|---|---|
| 과부하 | 불+전기 | 필살 피해 +8% |
| 빙결 협공 | 물+얼음 | 게이지 충전 +12% |
| 생명의 저주 | 풀+고스트 | 직접 피해 +8%, 지속 피해 제외 |
| 정신 집중 | 에스퍼+전기 | 치명타 +5%p |

신규 피해 보너스 합은 +45%, 신규 충전 +40%, 신규 공격 속도 +25%까지입니다.
지역·날씨·신규 강화의 결합 피해 및 충전 계수는 각각 최대 1.8배, 최종 치명타 확률은 최대 45%입니다.
기존 성장·개체값·공격 강화·속성 상성/무효는 별도로 유지합니다. 상한은 adventure.py의 BONUS_CAPS에서 조정합니다.

## 공동 보스와 트레이너 지원

공동 보스의 원래 HP 공식과 75초 기본 제한을 유지합니다.

- 100~70%: 일반 전투.
- 70% 이하: 최대 HP 8% 보호막, 한 번만 발동. 보호막 파괴 후 2.5초간 피해 +15%.
- 35% 이하: 광폭화, 남은 시간 소모 +15%.
- 보호막에 실제로 준 피해도 기여도에 포함합니다. 과도한 전면 섬광은 추가하지 않았습니다.

협동 다인전의 접속 중인 다른 생존 팀원만 지원할 수 있습니다. 정비 중/경쟁전/자기 자신/오프라인 대상은 거절합니다.

| 지원 | 비용 | 효과 |
|---|---:|---|
| 공격 | 80 | 전투 시간 10초간 피해 +10%, 중복 불가 |
| 긴급 방어 | 120 | 30초 안의 다음 생명 피해를 1 경감, 송신자당 경기 3회 |
| 필살기 | 100 | 배치 유닛 게이지 +30, 최대 100. 대상 재사용 15초 |

모든 지원에 송신자 공통 전투 시간 20초 재사용이 있습니다. 실패 시 코인을 차감하지 않습니다. 1인 협동전에서는 대상 없음 안내를 표시합니다. 경쟁전 습격(80코인/15초)은 유지합니다.

## 결과·경제·공정성

결과는 기존 순위/점수에 처치·누적 피해·보스 기여·전설 소환·합성/진화·미션·지원 횟수를 표시합니다.
MVP 기여 지수는 처치×2 + 누적 피해/100 + 보스 피해/50 + 지원×50 + 미션×60 + 생존 클리어 라운드×20입니다.
MVP 동률은 기존 점수, 낮은 참가자 번호 순입니다. 나머지 칭호는 양수 기록의 공동 1위 모두 수여하고 기록이 0이면 생략합니다. 공유는 사용자가 누른 결과 텍스트 복사만 제공합니다.

시작 240, 소환 40, 일반 처치 7, 중간보스 40, 일반 전장 보스 90, 황금 추가 40, 라운드 보상 60+3R, 공동 보스 200+10R입니다.
일반 정비 10초, 카드 정비 18초. 적 체력 계수 보통/도전/극한 0.75/1.15/1.7, 일반 적 수 min(16+2R,44), 출현 0.54초입니다. 샛길은 적 수 80%와 남은 거리 기반 HP 보정을 적용합니다.
클라이언트는 카드/지원 명령만 보내며 재화·피해·보상은 서버에서 검증합니다. 모든 경기 신규 상태는 재대결 시 초기화되고 재접속 시 복원됩니다.

## 저장소와 자산

GET /api/leaderboard?difficulty=normal|challenge|extreme 는 서버가 종료 결과에서 기록한 솔로 순위입니다. 공개 점수 등록 API는 없습니다.
SQLite는 Render 임시 저장소에서 재시작 시 사라질 수 있습니다. 서버 전용 DATABASE_URL(PostgreSQL/TLS)을 연결하면 영구 저장할 수 있으며 이 작업에서 외부 DB/서비스 설정을 변경하지 않았습니다.

비공식 팬 게임이며 포켓몬 관련 권리는 각 권리자에게 있습니다. 스프라이트 출처는 assets/sprites/SOURCE.md, 지역 배경 제작 기록은 assets/terrain-regions-v4.PROMPT.md입니다.
