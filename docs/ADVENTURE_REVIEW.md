# POKÉ LUCK 개선안 구현 결과
작성일: 2026-11-14 (한국 시간)
상태: 검토용 브랜치 codex/adventure-systems. 운영 게임/Render 설정 변경 없음.

## 1. 구현 완료
- 운명의 선택: 5/15/25/35/45R 성공 후 각 생존자에게 독립 카드 3장. 서버 검증, 중첩 제한, 18초 실제 시간 정비와 자동 선택, 카드 목록, 터치/클릭·선택 피드백.
- 특별 미션: 1/11/21/31/41R 개인 미션. 처치/무손실 방어/속성 수집/진화·합성/보스 기여를 서버 집계. 10라운드 구간 만료, 1회 자동 보상, 진행 바와 금빛 알림.
- 속성 시너지: 불+전기, 물+얼음, 풀+고스트, 에스퍼+전기. 각 속성 2마리 조건과 실시간 활성/해제, 선택 정보 표시.
- 공동 보스: HP 70% 보호막(최대 HP 8%, 1회), 파괴 후 2.5초 피해 +15%, HP 35% 광폭화(시간 소모 +15%). 보호막 피해도 기여도 집계.
- 협동 지원: 공격 80/방어 120/충전 100코인. 다른 접속 생존 팀원만, 송신자 공통 20 전투초 재사용. 공격 +10%/10 전투초, 방어 1피해 경감/30 전투초 유효·경기 3회, 게이지 +30·수신자 15 전투초 재사용.
- 결과: 기존 점수·순위 유지, 누적 피해/전설/진화/미션/지원 집계, MVP·칭호, 동률 규칙, 금빛 MVP와 결과 텍스트 복사.
- 기존 일러스트/스프라이트/지역/날씨/중첩 묶음 이동/유연한 최종 강화/경쟁전 습격을 유지. 문서·초기 UI를 24개 배치 지점, 최대 72마리 기준으로 정리.

## 3. 규칙과 상한
- 예시 카드 10종을 구현. 대부분 최대 2중첩, 진화 보상 카드는 최대 1중첩·라운드 2회(최대 60코인).
- 신규 피해 +45%, 충전 +40%, 공격 속도 +25%. 지역·날씨·신규 강화 결합 피해와 충전은 최대 1.8배, 최종 치명타 확률 최대 45%.
- 풀+고스트 시너지는 직접 피해만 올리며 지속 피해에는 해당 +8%를 재적용하지 않음.
- 미션 보상 100~150코인, 구간당 한 번. 처치 코인 +10%의 소수 부분은 이월해 작은 보상에서도 손실 없이 누적.
- 생명 회복은 개인 시작 상한 20 또는 협동 팀 시작 상한 20×인원 이내.
- 기존 경제(시작 240/소환 40/일반 처치 7/라운드 60+3R)와 기존 난이도 계수·보스 기본 HP·75초는 유지.
- 지원은 전투 시간 기준. 정비/경쟁전/자기 자신/오프라인·탈락 대상은 거절하고 실패 시 코인 차감 없음.
- MVP는 처치×2+누적 피해/100+보스 피해/50+지원×50+미션×60+생존 클리어 라운드×20.
- MVP 동률은 기존 점수, 낮은 참가자 번호. 나머지 칭호는 양수 기록의 공동 1위 모두 수여. 기여가 없으면 표시하지 않음.

## 4. 자동 검증
- python -m unittest discover: 112개 통과.
- 전체 assets/*.js의 node --check 및 test_motion.cjs 통과.
- 카드 임의 ID/중복 선택/중첩 상한/시간 만료 자동 선택.
- 미션 중복 보상·만료·무손실 연속 조건·진화 보상 상한.
- 시너지 판매 해제·직접/지속 피해 구분·결합 보너스 상한.
- 보스 보호막 파괴·광폭화·기여도.
- 지원 대상/비용/중복/재사용·게이지 상한·공유 생명 1에서의 방어 경감.
- 실제 aiohttp 3인 WebSocket에서 카드 선택·재접속 복원·지원 비용 조작 무시·재사용 거절.
- 1/2/3인 × 경쟁/협동 6조건에서 50R 상태 진행·다섯 번 카드 선택·결과·재대결 초기화.
- 실제 로컬 서버와 WebSocket을 연결한 Chromium: 기존 10개 화면 크기, 카드 팝업 1366×768/915×412/667×375/390×844, 전략 패널/활성 시너지/지원/보스 2·3단계/MVP/결과 복사, 브라우저 오류 0건.
- 결과 복사는 테스트용 브라우저 클립보드 대체 객체로 검증해 사용자 시스템 클립보드는 변경하지 않음.

## 5. 밸런스·성능 관찰
같은 자동 소환·합성·재배치 전략, 시드 7/19/42 비교(새 카드는 서버 자동 선택). 이 결과는 최적 플레이나 실제 승률의 증명이 아님.

| 난이도 | 운영 코드 도달 라운드 | 새 코드 도달 라운드 |
|---|---|---|
| 보통 | 50 / 50 / 35 | 50 / 50 / 50 |
| 도전 | 34 / 35 / 37 | 50 / 45 / 41 |
| 극한 | 28 / 28 / 31 | 28 / 32 / 26 |

보통은 신규 성장으로 쉬워지고, 도전/극한의 차이는 남아 있음. 표본이 작고 새 난수 소비가 달라 개별 시드끼리 완전한 동일 환경 비교는 아님. 기존 적 체력을 임의로 높이지 않았으며 실제 선택률·승률 수집 후 후속 조정을 권장.

3인·216유닛·120적의 전투 계산 반복(적 이동은 고정):
- 운영 평균 0.95ms / p95 1.85ms.
- 새 코드 평균 1.39ms / p95 2.58ms.
이는 로컬 전투 계산 수치이며 스냅샷 직렬화·네트워크 지연·모바일 FPS를 포함하지 않음.

## 6. 시각 검토 및 한계
- 캡처로 데스크톱 카드/전략 패널, 보스 보호막·광폭화, MVP 결과의 배치와 가독성을 검토.
- 모바일은 Chromium 화면 크기 에뮬레이션이며 실제 휴대전화 3대에서 인터넷 플레이/터치/클립보드를 검증하지 않음.
- 브라우저 연출 검사는 로컬 전용 장면 주입을 사용. 해당 도우미와 가짜 팀원은 저장소/운영 서버에 포함하지 않음. 3인 규칙·재접속·지원 네트워크 검사는 독립적인 실제 WebSocket으로 수행.
- 운영 배포/Render 서비스·환경변수·DB 설정 변경 없음. 현재 공개 게임에는 아직 새 기능이 없음.
- 새 카드·미션·시너지 상태는 경기 메모리이며 서버 재시작 시 초기화됨. 기존 랭킹의 SQLite 임시 저장 제한은 유지.
- 카드별 선택률과 실제 사용자 승률은 아직 없음. 한 카드가 항상 최적이 아니라는 통계적 보장은 하지 않음.

## 7. 후속 추천
- 플레이테스트에서 카드 선택률, 구간별 탈락률, 보스 보호막 소요 시간을 먼저 수집.
- 보통 난이도 숙련자에게 너무 쉬우면 카드 수치/미션 보상을 먼저 미세 조정하고 전체 적 체력 일괄 상향은 피하기.
- 실제 모바일 3대의 협동 플레이와 연결 끊김/복원, 저사양 기기 FPS 확인 후 병합 검토.
- 카드 수치·임계치는 adventure.py의 설정을 중심으로 조정.
